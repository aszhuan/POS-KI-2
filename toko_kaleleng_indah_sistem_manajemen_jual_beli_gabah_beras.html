Koneksi Cloud & Akses Online via Link

Hubungkan ke Google Apps Script, GitHub Gist, atau bagikan link akses online.

Cara Menghubungkan ke Google Sheets / Apps Script:

1. Buka Google Sheets baru → menu Extensions > Apps Script, tempel kode di bawah, lalu klik Deploy > New Deployment > Web App (Anyone).

2. Salin URL Web App (`https://script.google.com/macros/s/.../exec`) dan tempel di kolom berikut.

Kode Google Apps Script (`Code.gs`) Siap Pakai:

1. Sinkronisasi Database via GitHub Gist API:

Simpan database toko ke GitHub Gist pribadi menggunakan GitHub Personal Access Token (scope: gist).

2. Cara Membuat Link Online Permanen di GitHub Pages:

Unduh file aplikasi HTML ini, unggah ke repositori GitHub sebagai index.html, lalu aktifkan Settings > Pages > Branch: main. Aplikasi Toko Kaleleng Indah langsung memiliki link online HTTPS (misal: https://username.github.io/toko-kaleleng-indah) yang bisa dibuka dari HP mana saja.

Bagikan Link Akses Online (Snapshot Data Terenkode):

Buat tautan khusus yang membawa seluruh data stok, harga, dan transaksi toko Anda. Jika link ini dibuka di perangkat/HP lain, data toko otomatis termuat.

Unduh atau pulihkan seluruh database toko ke file JSON.
